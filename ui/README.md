# Multiprint Frontend Vue JavaScript

Replikasi frontend Vue tanpa TypeScript. Tampilan dan flow mengikuti frontend lama.

## Local

```powershell
cd FrontendVue
npm install
npm run dev
```

Default frontend berjalan di `http://localhost:5174` dan memakai:

```env
VITE_API_BASE_URL=http://localhost:5002/api
```
